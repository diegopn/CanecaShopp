# CanecaShopp

Projeto acadêmico desenvolvido para a disciplina de **Engenharia de Software** do **PPGI de CP**.

## Sobre

O repositório reúne a implementação do projeto acadêmico e seus artefatos de desenvolvimento. Ele faz parte da categoria **Mestrado/PPGI** no portfólio do autor.

## Tecnologias

- Java
- Maven

## Estrutura

- `src/`: código-fonte do projeto.
- `pom.xml`: configuração do projeto Maven.
- `.gitignore`: arquivos e diretórios ignorados pelo Git.

## Execução

Para importar o projeto, abra-o em uma IDE compatível com Maven ou execute os comandos Maven a partir da raiz do repositório.
